## 📌 Project Information

* **Project Name:** Pawfect Match
* **Type:** Pet Adoption Management System
* **Tech Stack:** Next.js, React, Node.js, MongoDB, Stripe

---

## 🚀 Live Features Overview

Pawfect Match is a complete pet care platform that integrates:

* 🐶 Pet Adoption System
* 🛒 E-commerce (Food & Accessories)
* 💉 Pet Healthcare (Vaccination Workflow)

It uses a **role-based system** with dedicated dashboards for:

* Admin
* User
* Shelter
* Doctor

## 🌟 Key Features

### 🧑‍🤝‍🧑 Role-Based System

* Admin, User, Shelter, Doctor roles
* Separate dashboards for each role
* Controlled access to features

### 📊 Multi Dashboard

* Admin → Full system control
* User → Orders, Adoption, Requests
* Shelter → Pet management
* Doctor → Vaccine management

### 🐾 Pet Adoption System

* Shelter adds pets
* Users apply for adoption
* Admin approval process
* Final adoption confirmation

### 🛒 E-commerce System

#### Pet Food

* Browse products
* Add to cart / Buy now
* Checkout & order tracking

#### Accessories

* Separate category
* Same purchase flow

### 🛍️ Shopping Cart

* Add / Remove items
* Multi-item checkout

### 💳 Payment System

* Cash on Delivery
* Stripe Online Payment
* Payment tracking

### 📦 Order Management

* User → Order history

### 💉 Vaccine System

* User submits request

### 🐕 Pet Management

* Shelter manages pets

### 🔔 Notification System

* Order updates

## 🧠 Why Next.js?

We used Next.js because:

* ⚡ Faster performance (SSR & SSG)
* 🔍 SEO friendly (important for pet listings)
* 📁 Built-in routing system
* 🔌 API routes support
* 🚀 Scalable & production-ready
